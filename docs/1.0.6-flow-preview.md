# 1.0.6 流程图测试版

独立程序：`build/preview-1.0.6/AllianceBossStrategyStudio-1.0.6.exe`。此测试版不替换 `build/release/AllianceBossStrategyStudio.exe`，原来的桌面快捷方式仍打开 1.0.5。

## 使用

1. 打开测试版，选择策略组，点击“从列表创建流程图”。已有流程则点击“打开流程图”。转换保留原列表。
2. 拖动节点标题调整位置；点击一个出口，再点击目标节点即可连线，也可以在右侧选择出口连接到哪里。
3. “添加节点”可以添加条件分支、技能动作、保留技能、等待、首回合技能、自动试炼备用。选中节点后配置条件和技能，或将其设为入口。
4. 点击“检查连线”，处理断线、循环、不可到达节点等提示；勾选“使用流程图执行”，保存策略。
5. 已在运行时，编辑的是草稿。保存后暂停并重新接管，才会使用新流程。每次行动从入口重新判断，选到一个合法动作即结束本次决策。

可搜索节点、整理布局、缩放、撤销和重做；多个分支可以连接到同一个备用动作。画布位置不代表执行顺序，入口和连线才代表顺序。第一版最多 80 个节点，不支持循环和跨回合内部计数器。

## 分支和保留技能

- **技能动作**：条件未满足与技能/目标不可用是两个不同的出口；动作选中后结束本次决策，执行层继续检查实际技能和合法目标。
- **条件分支**：只检查条件和配置的目标范围，分别走满足/不满足出口。这里不会释放配置的技能；后续动作独立检查自己的目标。
- **保留技能**：设置适用条件、需要保留的技能，以及唯一指定的动作节点。条件满足后，本次决策中其他节点不能消耗该技能，指定节点可以释放。下一次行动重新判断，条件失效即可解除。
- **等待**：结束本次判断，不尝试后面的备用技能；控制器保持等待，不等于关闭整个控制器。
- 旧列表转换后的试炼专用规则继续自动保留技能；严格规则原有的保留语义也保留。**把试炼条件单独放在条件分支中，并不会自动替后面的无试炼条件动作保留技能**，这时请连接保留技能节点。

旧规则转换包含首回合阶段、严格规则、自动试炼、默认技能及自动试炼备用阶段，保留原来的阶段顺序。新增节点可以自由连接，旧列表仍保留为切回列表执行的备份；两种编辑方式不会自动互相覆盖。

## 离线试跑与日志

“导入快照离线试跑”只计算上传 JSON 中的数据，不读取游戏、不发出游戏指令。快照需要完整的 `skills`、`heroes`、`bosses`、当前英雄、战斗和 Boss 状态；支持直接快照以及 `state`/`snapshot` 包装。普通日志摘要不等于完整快照。这是单次行动决策回放，尚不是整场战斗模拟。

离线结果显示选择的动作及路径。正在运行时，点击“检查连线”后，仅高亮执行内容版本相同的实时路径，避免将旧策略的执行结果套在新草稿上。主界面的“规则命中解释”和诊断文件也记录节点编号、出口、下一节点、保留技能和流程版本。

## 配置隔离

默认测试数据目录：`%LOCALAPPDATA%\WFQ-GAFE\RaidBossStrategyStudio-Flow-1.0.6`。首次启动复制已有 1.0.5 的策略、界面偏好和两份目录缓存，之后独立保存。不会覆盖稳定版配置。两个版本仍共用原有的接管互斥机制，同一游戏进程只应由一个版本接管。

含流程图的导出文件使用格式版本 2，1.0.5 会拒绝导入，避免旧版本忽略流程图而误执行列表备份。测试版可以继续导入原格式版本 1 的策略。

流程图界面第一阶段使用中文，复杂条件编辑仍复用原有条件编辑器；以后可再将常用条件拆成更简洁的独立节点参数。
