# 1.0.5 重复技能选项修复

同一英雄的不同培养阶段可能使用不同技能编号，但仍占用同一个技能按钮。原先合并技能目录时只按编号保留条目，会把三技能的两个版本同时列出。本地目录中地卜法师的 48804 和旧 48803 都标记为同一形态的第三个技能，因而显示四个选项。

修复后按形态和已观察到的技能位置合并，新观察优先，读取旧缓存时也清理重复项。真正处于第四个位置的技能，以及变身后的另一形态技能都会保留，不按名称去重，也不把所有英雄强行限制为三个技能。

同时取消跨技能编号按位置套用名称、描述和标记的逻辑；已确认隐藏或被动的技能不会从旧缓存中被重新追加。

不修改已保存策略中的执行编号。运行时仍要求技能编号和可用技能一致，不会仅因位置相同就强行施放另一个编号。当前用户配置里的地卜法师默认顺序包含两个版本，真实可用的版本仍由原有执行校验选择。

验证：15 组离线测试；打包后的实际服务代码通过 5 个目录回归测试。对用户缓存的只读审计中，仅地卜法师从四项清理为三项。版本继续为 1.0.5，启动新版时会自动规范化目录缓存。
