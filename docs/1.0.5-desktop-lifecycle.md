# 1.0.5 启动与退出流程修复

固定发布入口保持 `build/release/AllianceBossStrategyStudio.exe`，版本仍为 1.0.5。

## 修复

- 单文件程序原先直接使用解包临时目录中的代理 DLL；游戏继续加载该 DLL 时，程序退出无法删除临时目录。现在先校验并复制到用户数据目录 `runtime/agents/<SHA256>/RaidChimeraAgent.dll`，同内容复用、不覆盖已加载的 DLL。旧目录不强制删除。
- 关窗立即取消窗口初始化与接管准备；停止显示窗口、页面重试、后续控制器启动和新的图片预加载。
- 只读初始化助手可取消并回收；已派发的加载操作按原有有界超时收尾，父进程等待助手释放资源，取消后不再继续接管。
- WebView2 未初始化时也释放控件；关闭后忽略迟到的初始化回调；脚本任务异常或关窗时释放等待者，避免线程一直等待和异步回调异常。
- 临时配置删除失败记录为清理延后，不打断状态与进程清理；保存后的临时文件清理失败不会错误报告保存失败，真实写入失败仍保留。
- 浏览器断开连接不再尝试二次发送错误响应。正常结束显示“已完成/已暂停”，退出码仍保留在结构化日志。
- 服务或 HTTP 初始化失败时释放已经创建的资源与单实例锁；真正启动失败仅提示一次，内部助手不弹桌面错误框。
- 桌面启动、关闭、异常和 WebView2 警告写入用户数据目录 `logs/desktop-lifecycle.log`，每个文件 1 MiB，保留 3 个轮转文件。控制器取消与临时配置清理事件写入已有诊断日志。
- 合入技能目录去重修复，保留真正的第四主动技能与不同形态的技能。
- 原生与 Python 代理构建标识同步更新为 2026091201，让用户下次启动接管时识别需要更新的旧代理。

## 验证范围

新增离线测试覆盖持久 DLL、关闭时序、助手取消/回收、原子保存、断连、初始化失败清理及 vendored WebView2 的真实方法。验证不向游戏发送操作，也不修改用户策略。

发布前通过 16 组离线测试（含 19 个桌面生命周期用例）、2 个原生测试和 35 个打包代码回归用例。以普通权限运行发行 EXE 的两个内部助手 `--help`，确认正常退出、解包临时目录已清理、持久 DLL 内容与包内一致。固定 release 发布后再次核对 SHA-256；记录保存在 `out/desktop-lifecycle-20260912/`。

历史弹窗没有截图或调用栈，因此不能断言每次都来自同一个问题；本次修复的是代码中确认存在的失败路径。新的桌面日志用于进一步区分真实启动失败和退出收尾问题。
