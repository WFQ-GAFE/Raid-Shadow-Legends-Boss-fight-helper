# 1.0.5 日志阅读与试炼专用技能保留

## 日志阅读

小日志窗和放大日志窗仅在读者停留底部时跟随更新。上翻后保留当前阅读内容和滚动位置，后台仍持续收集日志；滑回底部恢复最新记录。阅读快照也避免后台 800 条记录上限、以及小窗 200 条上限淘汰旧记录时把正在阅读的文字挤走。清空日志和切换 Boss 模式会重置阅读视图。

## 技能规则

此前严格规则的保留技能只约束默认技能顺序与自动试炼规划，普通直接施放规则和首回合配置可绕过保留。

现在含试炼条件的直接施放／变形规则，在其英雄、形态与试炼范围成立时持有该技能。其他普通规则、默认顺序和首回合配置不能使用同一技能；符合完整条件的试炼专用规则可以施放。如果同一技能有多条适用试炼规则，其中任意一条完整匹配即可施放，普通规则在列表中的先后位置不影响保留。

若使用“当前可执行试炼”条件，试炼完成或退出当前可执行范围会释放保留；其他试炼条件按各自含义判断。显式配置了试炼专用 A1 时也会保留；若无可用备用动作，沿用已有的无匹配规则暂停行为。没有試炼条件的一般严格规则维持原行为。

出手诊断新增 `skill_reserved_for_trial_rule`，记录被拦截技能和为其保留技能的规则名称。无需修改现有策略文件。
