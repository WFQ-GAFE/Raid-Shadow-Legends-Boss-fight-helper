- 20 个项目 Python 运行模块与发布 EXE 中的代码对象核对一致；核对时只忽略源码路径和行号信息。

## 获取源码

```powershell
git clone --recurse-submodules --branch v1.0.5 https://github.com/WFQ-GAFE/Raid-Shadow-Legends-Boss-fight-helper.git
cd Raid-Shadow-Legends-Boss-fight-helper
```

已有克隆可运行 `git submodule update --init --recursive` 获取锁定版本的 MinHook。GitHub 自动生成的 Source code 压缩包不包含子模块内容，构建时推荐使用上述克隆方式。

## 离线检查与构建

本次使用 Windows x64、Python 3.13、Node.js/npm、Visual Studio 2022 C++ 工具链及 CMake。

```powershell
python tools/run_offline_tests.py
python -m unittest discover -s offline_sim/tests
npm --prefix ui ci
npm --prefix ui test
npm --prefix ui run build
cmake -S src/agent -B build/agent-1236 -A x64
cmake --build build/agent-1236 --config Release
ctest --test-dir build/agent-1236 -C Release --output-on-failure
```

生成 EXE 还需要补齐未纳入 Git 的第三方二进制依赖，包括 PyInstaller 启动器、pywebview/pythonnet 运行库及 UnityPy 的原生解码依赖。版本和许可证见 `THIRD_PARTY_NOTICES.md`。保留仓库对 `third_party/python/webview/platforms/edgechromium.py` 的本地修复，不要用未经修补的上游文件替换它。

依赖准备好后运行 `tools/build_chimera_desktop.ps1 -SkipPublish` 生成独立构建包；验证后按 [通用 release 流程](release-workflow.md) 发布。

用户策略、运行日志、资源缓存和本机构建产物不属于源码发布内容。
