# 1.0.5 试炼保留诊断引发黑屏的修复

## 已确认的触发路径

2026-09-14 03:20:49.551997（北京时间），诊断日志 `decisions-20260913T191808501383Z-6acbbe835a8a.jsonl` 出现 `skill_reserved_for_trial_rule` 记录，技能 98903，规则“第一总督阿莫科 · 遗产守护者 → 自己”。记录包含 rule/reason/skillTypeId/reservedByRules，却没有普通规则诊断的 conditions 数组。

上一版前端对每条规则诊断直接调用 `row.conditions.map()`。后台推送这条记录后会抛出 TypeError；没有根错误边界的 React 界面被卸载，只留下深色背景。`details` 面板即使收起仍然参与渲染，所以无用户操作也会发生。用户确认当时没有操作，界面为中文。

调查时工具进程仍响应，本地 HTTP 静态界面返回 200，控制器日志继续产生。此前桌面日志没有捕获前端渲染异常，所以未显示相应错误。排查没有关闭或重启工具，没有向游戏发出动作。

## 修复

- 后端保留诊断补全 name/kind/outcome/conditions 字段。
- 前端诊断行兼容之前已产生的缺字段记录；保留技能时明确显示保留原因与对应规则，不再依赖每行都有 conditions。
- 加入 React 根错误边界：显示错误页、恢复界面按钮以及由用户点击的暂停接管入口，不自动停止或重启控制器。
- 前端 JavaScript、Promise 和渲染错误通过带会话认证的接口写入 `logs/desktop-lifecycle.log`。仅接收有长度限制的错误字符串，清除 URL 中的会话 token，不上传整份界面状态；前端每分钟最多报告 5 次。
- 保留上一版日志阅读与试炼技能保留功能，版本仍为 1.0.5。

## 验证

使用事故中相同字段的诊断行，复现旧版 conditions.map 异常，并用实际 React 服务端渲染验证修复后的 DecisionRows。另验证混合/缺字段记录、错误页操作入口、后端诊断格式和错误接口的长度及脱敏约束。

验证与发布记录位于 `out/black-screen-fix-20260914/`。
